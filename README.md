# I2C-UVM-

This project focuses on the functional verification of the Inter-Integrated Circuit (I2C) protocol using UVM at a standard clock frequency of 100 kHz. The design includes an I2C master and slave supporting both read and write operations with proper handling of START, STOP, ACK/NACK conditions, and serial data transfer over SDA and SCL lines. The verification environment is developed using UVM, consisting of sequence item, sequence, driver, monitor, agent, scoreboard, and environment to generate and validate different I2C transactions. A self-checking mechanism ensures correct data transfer between master and slave, while also verifying protocol compliance such as address matching, acknowledgment handling, and timing behavior. Simulation results confirm reliable communication at 100 kHz without protocol violations, demonstrating correct functionality of the I2C protocol suitable for embedded and SoC applications.
